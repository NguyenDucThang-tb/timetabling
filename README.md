# Timetabling Optimization (AI Scheduling)

## 📌 Description
This project solves the school timetabling problem using:
- Greedy Algorithm
- Genetic Algorithm
- Local Search (Tabu / Hill Climbing)
- Backtracking Repair

## ⚙️ Pipeline
Greedy → GA → Local Search → Repair

## 📂 Structure
- greedy.py: initial solution
- ga.py: global optimization
- local_search.py: fine-tuning
- repair.py: fix hard constraints

## ▶️ Run
```bash
python main.py
